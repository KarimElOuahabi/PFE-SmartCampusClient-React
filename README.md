# Smart Campus: Frontend

Web client for **Smart Campus**, my Licence final-year project (PFE). Administrators, teachers and students manage schedules, assignments, marks, administrative documents and reclamations (requests and complaints) in one place.

## Features

- **User types:** `Admin`, `Teacher` and `Student`, each with their own login and menu.
- **Schedules:** create, edit and preview timetables, with a calendar view on the home page.
- **Assignments:** create, edit and view assignments.
- **Marks:** teachers enter marks and students see their own.
- **Reclamations:** students submit requests and administrators handle them.
- **Administrative documents:** manage and request official documents.
- **Academic structure:** CRUD pages for departments, fields, subjects, students, teachers and admins.

## Tech stack

React 19 · TypeScript · React Router 7 · Ant Design 5 · Tailwind CSS 4 · day.js
